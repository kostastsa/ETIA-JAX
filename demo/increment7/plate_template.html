What ETIA, causalnex and cdt do

PartWhat happensETIA-JAX
NOTEARS parametersETIA gives only threshold to causalnex. The max_iter and h_tol of its grid have no effect: causalnex uses 100 and 1e-8. Thus the 27 grid points give 3 different results.etia_compat: the same. Default: the given values.
NOTEARS datacausalnex does not center the data, and its score has no intercept.Default: centered data.
NOTEARS at threshold 0All weights stay. ETIA writes each edge into one matrix, and in a 2-cycle the later edge wins. The result is the complete DAG with j → i for each i < j.etia_compat: the same. Default: a DAG (the smallest weight on a cycle goes).
SAM outputETIA keeps the averaged filters as a weighted DiGraph, with no threshold. cdt divides the sum of the test batches by the number of test epochs only, so the values go up to the number of batches.etia_compat: the same W. Default: W in [0, 1] and the DAG of W > 0.5.
SAM graph matrixpywhy_graph_to_matrix writes all the edges of the DiGraph. The result is the complete DAG with j → i for each i < j, for all data.etia_compat: the same.
SAM mixed datacdt takes the skeleton column at the index of the variable. When a categorical variable comes first, a generator gets the wrong inputs.Default: the correct inputs.
SAM processescdt starts its runs in forked processes. When the parent process already uses CUDA, the runs stop with an error, and cdt waits with no end.One process: the 8 runs are one vmap.
CausalLearnerThe k-fold protocol expects three return values. NOTEARS and SAM return two, so the protocol stops with a ValueError. NOTEARS also ignores the rows of the fold.Increment 9.
