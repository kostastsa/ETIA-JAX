INCREMENT 7 · NEXT

NOTEARS and SAM with optax

NOTEARS

A continuous optimization of a weighted adjacency matrix with the acyclicity constraint h(W) = tr(exp(W ∘ W)) − d = 0, solved with an augmented Lagrangian and optax.

SAM

A structural agnostic model: generators and a discriminator trained adversarially, with a sparsity and acyclicity penalty, in JAX with optax.

Checks

These algorithms are random, so the checks compare the accuracy (SHD) and the run time with ETIA's implementations on the same data.
