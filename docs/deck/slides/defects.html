WHAT THE PORT FOUND IN TETRAD 7.6.5

Defects that ETIA has, kept only in the Tetrad mode

Threads

FCI, its family and GFCI use one CI test object from parallel threads. Chi-square and G-square are not thread-safe: searches crash or get incorrect p-values. R4 runs in a random sequence.

Search steps

The "stable" FAS is not stable. colliderAllowed has a typo. R4 accepts only the shortest discriminating paths. R10 does not change marks. GFCI has no Possible-D-SEP step.

Statistics

CCI uses the wrong rows. DG-LRT uses a wrong mean. The BDeu prior uses the number of rows. The discrete BIC prior has the wrong sign. FGES stops at a degree of ceil(ln n).

Separating sets

CPC does not search a side with one node. GFCI keeps a set only if all subsets show independence, and it does not search adj(y). DagToPag is not exact.
