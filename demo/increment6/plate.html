PartWhat happensETIA-JAX
ETIA lagged dataDataset.convert_to_time_lag is empty: the user must give the lagged columns (X1, X1:1, …). The tigramite algorithms run only on raw series.lagged_table makes the table; Knowledge.time_lagged makes ETIA's tiers.
