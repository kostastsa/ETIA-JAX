Two modes

tetrad_compat=True gives the same output as ETIA. It copies the Tetrad defects and the sequence of the Java hash sets. The default mode is the correct algorithm, and the d-separation oracle tests it.

References

ETIA and Tetrad run in the ETIA venv (Python 3.10, Java 17). The tests compare ETIA-JAX with their saved outputs.

Defects

The README lists each Tetrad defect that the port found. The default mode does not have these defects.
