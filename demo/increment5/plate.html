What Tetrad 7.6.5 does in the scores, FGES and GFCI

PartWhat Tetrad doesETIA-JAX
FGES degree limitFGES takes the score's getMaxDegree(): no new edge at a node with ⌈ln n⌉ edges (1000 for discrete BIC).Default: no limit. tetrad_compat: the same as Tetrad.
BDeu structure priorThe prior uses N − 1 (N = number of rows) where it should use the number of other variables.Default: p − 1. tetrad_compat: N − 1.
Discrete BIC structure priorThe prior term has the wrong sign: more parents give a higher score.Default: the log prior. tetrad_compat: the same as Tetrad.
GFCI separating sets (MinP)Takes the subset of adj(x) with the smallest p-value and keeps it only if that p-value is above alpha (all subsets must show independence); the second search uses adj(x) again, so adj(y) is never searched.Default: the first separating set among the subsets of adj(x) or adj(y). tetrad_compat: the same as Tetrad.
GFCI stepsNo Possible-D-SEP step. FGES inside GFCI assumes faithfulness (two rounds) and has no degree limit.Default: the Possible-D-SEP step of the paper, and separating sets for the pairs that FGES did not connect (needed by R4).
Threads (GFCI)The MinP search tests subsets from parallel threads on one CI test object: χ² and G² searches crash or get incorrect p-values.No threads; the fixtures use a race-free Tetrad (serialized test calls).
R4 order (GFCI)As in FCI: parallel R4 tasks over a HashSet with identity hashes; the PAG can change between runs.A fixed order; the graph before R4 is always the same as in Tetrad, and the PAG is one of Tetrad's outputs.
