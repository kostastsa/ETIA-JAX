What ETIA, MXM and Rfast do

PartWhat happensETIA-JAX
Rfast cor.fbedWhen the forward phase selects exactly one column, z stays a vector and the K phase stops with "'x' is not a matrix". ETIA uses K = 3 or 5, so FBED fails and ETIA skips the fold.etia_compat: the same error, the fold is skipped. Default: FBED continues.
FBED statisticscor.fbed compares a Fisher z statistic with a t quantile. The p-value of the first column uses n − 2 degrees of freedom. The backward phase uses lm on the raw data.The same in both modes (these are the definitions of MXM).
SESThe univariate statistics keep their sign, and ties of p-values go to the larger statistic. SES conditions only on selected columns, so it can keep a descendant of the target.The same in both modes.
FoldsThe protocol has folds_to_run: 2, but all 5 folds run.Default: only folds_to_run folds.
"Bootstrap bias correction"A plain bootstrap of the pooled test predictions of the winner. It does not correct the bias of the choice of the winner. It runs in joblib workers without a seed.Default: BBC-CV (each bootstrap sample selects the winner on the in-bag rows and scores it on the out-of-bag rows).
No selected columnFor the main target, ETIA returns the selection of the last target of the list.Default: the selection of the main target.
Random forestsklearn random forests with random_state=42.An MLP in JAX (32 or 64 hidden units); its scores are not those of ETIA.
R callsEach FS call writes a CSV file and starts R (about 2 s). The same FS runs again for each model.No R; one FS result per fold for all models.
