What ETIA and Tetrad do

PartWhat happensETIA-JAX
Random MAGThe Markov boundaries come from one random DAG or MAG of Tetrad (dagFromCpdag, magFromPag). Java draws the random numbers without a seed from Python, so the scores and the winner change from run to run, also with random_seed and one job.etia_compat: a port of Tetrad's draw (same distribution, seeded). Default: the Markov boundary of the class, which is the same in all its graphs.
Undirected edgesmagFromPag can set a tail at both ends of an edge. ETIA's markov_boundary does not see such a neighbor. FGES has causal_sufficiency: [False], so its CPDAG also goes through magFromPag and loses all its undirected neighbors.etia_compat: the same. Default: no undirected edge in the DAG or MAG.
joblib workersWith n_jobs above 1 (ETIA's default: all cores), the workers change copies of the OCT object. The Markov boundary sizes stay 0 and the p-values stay 1, so the permutation test and the sparsity rule have no effect.etia_compat: the same; etia_n_jobs=1 gives ETIA's run without workers. Default: both work.
Final graphThe configuration keeps the indexes of the last fold, so the final graph comes from the training rows of that fold, not from all the rows.Default: all the rows.
Empty Markov boundaryUniform random predictions between the minimum and the maximum of the training values. A constant prediction would make the mutual information stop with "zero st_dev".Default: the training mean (or the most frequent value), score 0.
Categorical nodesThe regressor predicts the category codes, and mutual_info_score takes each predicted value as a label.Default: a classifier forest (Gini) and the predicted labels.
Two methodsget_best_model_between_algorithms unpacks three values into two names. get_best_model_between_family compares a list with a bool and reads a key that the table does not have.etia_compat: the same errors. Default: they work.
NOTEARS, SAM, tigramiteTheir wrappers return two values, and the k-fold protocol expects three: the OCT stops with ValueError.Default: NOTEARS and SAM run on the rows of the fold.
ConfigurationsConfigurations changes the global default_conf. A second CausalLearner in the same Python session keeps the algorithms of the first dataset. With the defaults (no causal sufficiency, faithfulness), only FCI and FCI-Max run on continuous data.A new table for each learner.
Tetrad on discrete dataR0 of FCI runs the chi-square or G-square test in a parallel stream, and the test is not thread-safe. ETIA's OCT on disc10_s0 stopped with Java errors in all 4 tries. With one processor, IndTestFisherZ divides by zero.No threads. The reference for discrete data uses a lock around each test.
